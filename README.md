# 日常拾光 GitHub Pages 模板

## 使用方式
1. 建立 GitHub repository。
2. 將本資料夾所有檔案上傳到 repository 根目錄。
3. 到 Settings → Pages。
4. Source 選擇 Deploy from a branch。
5. Branch 選 main，資料夾選 /(root)，儲存。
6. 等待 GitHub Pages 完成部署。

## 修改
- 首頁：`index.html`
- 分類：`categories.html`
- 生活學習：`life.html`
- 攝影筆記：`photo.html`
- 心情記事：`mood.html`
- 關於我：`about.html`
- 樣式：`assets/css/style.css`
- 深色模式與手機選單：`assets/js/main.js`
- 示範文章：`articles/`

深色模式會記住訪客上一次的選擇；第一次造訪則依系統深淺色設定顯示。
